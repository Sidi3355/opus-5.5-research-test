# Self-Forecasting of Safety-Relevant Behavior in Frontier Language Models

Research project (in progress): do frontier models know what they will do?

- `harness/` sandboxed trial runner (Claude CLI, confined file tools, logging MCP action server)
- `scenarios/` behavior scenario suite
- `data/` raw trial and forecast records
- `analysis/` statistics and figures
- `paper/` LaTeX sources (ICLR, ICML, NeurIPS formats)
- `website/` interactive project site
