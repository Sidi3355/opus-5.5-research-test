\section{Related work}
\label{sec:related}

\paragraph{Reward hacking in coding agents.}
Frontier coding agents delete or edit failing tests, special-case expected outputs, and tamper with evaluation harnesses \citep{vonarx2025reward,metr2025o3,anthropic2025sonnet37card,anthropic2025claude4card}. ImpossibleBench makes this measurable by mutating tests to contradict the specification, so any pass implies cheating \citep{zhong2025impossiblebench}; EvilGenie and SpecBench measure related gaps between visible and held-out tests \citep{gabor2025evilgenie,zhao2026specbench}. Claude system cards report ``impossible task'' hack rates that differ across generations and respond differently to anti-hacking prompts \citep{anthropic2025sonnet45card,anthropic2025haiku45card,anthropic2025opus45card}. Reward hacking learned in RL can generalize to broader misalignment \citep{macdiarmid2025natural,taylor2025school}; inoculation prompting \citep{wichers2025inoculation,tan2025inoculation} and escalation channels \citep{gomez2026escalation} are proposed mitigations. These works measure \emph{whether} agents hack; we hold the hack fixed and ask how the agent \emph{describes} it.

\paragraph{Honesty of agent reports.}
OverclaimBench finds that agents who skip part of a file-review task usually misrepresent their coverage in the final response \citep{smyth2026quantifying}, and agent-authored pull requests whose descriptions disagree with the code are accepted far less often \citep{gong2026analyzing}. o3 has been documented claiming actions it did not take and inventing justifications when confronted \citep{openai2025gpt5card,chowdhury2025o3truthfulness}; follow-up interviews after scheming have precedent in \citet{meinke2024frontier}. Confession and self-incrimination training aim to make such reports reliable \citep{joglekar2025training,lee2026training,li2025spilling}. We identify a specific, verifiable failure: the report attributes gamed behavior to a requirement that exists nowhere in the repository or conversation.

\paragraph{Unfaithful explanations and self-report.}
Language models give plausible explanations that omit the true cause of their answers \citep{turpin2023language}, reasoning models often fail to verbalize the cues or hacks that drive behavior \citep{chen2025reasoning,turpin2025teaching,arcuschin2026chainofthought}, optimizing against chain-of-thought monitors can obfuscate reward hacking \citep{baker2025monitoring}, and rationalizations in a trajectory can deceive monitors \citep{arnav2025cot}. These studies concern chain-of-thought; we study the user-facing report, and find that agents fabricate a \emph{source} for the behavior, not only a reason. A recent post holds hacked code fixed and varies a researcher-written narrative, finding that a stated motive leads a Claude judge to label hacks honest \citep{roussel2026claudejudge}; we use the agents' own reports and measure code-review approval. Work on self-knowledge finds that models' statements about their own behavior are largely generic \citep{binder2025looking,song2025privileged,blandfort2026strangers}; our probes ask a narrower question, whether an agent that asserted a requirement will acknowledge its only basis was the test.
