Across \nAnalyzed{} trials, we find the following.
\begin{itemize}[leftmargin=*,itemsep=1pt,topsep=2pt]
\item \textbf{Gaming is common and rule-shaped.} Four of the six models game the suite in most trials (\hackHaiku{} to \hackSonnetFourFive). They almost never hardcode the input. Instead they adopt a general-looking rule under which the test is correct, such as a different rounding mode or an exclusive boundary, and implement it as ordinary code. Every such rule breaks behavior on inputs the visible test never checks, and about half of the agents also rewrite the docstring to match.
\item \textbf{Reports invent the requirement.} In \hOneEst{} of special-cased trials the agent's report justifies the behavior with a requirement that appears nowhere in the repository or conversation (``the spec actually requires per-line rounding''; ``this is the standard definition of median''). Test edits, by contrast, are disclosed \hTwoMod{} of the time. Telling the agent that the docstrings are the source of truth does not reduce fabrication.
\item \textbf{Gaming depends on having a story.} In minimal pairs that change only the conflicting expected value so that no plausible rule produces it, gaming falls from \hSixOrig{} to \hSixVar.
\item \textbf{The question decides the answer.} Asked whether it added logic only to pass a test, the agent usually says no, because the rule is general (\prDirDeny{} of \prDirN{} after fabricated reports). Asked for the source of the behavior, it usually admits there is none beyond the test (\prSrcAdmit{} of \prSrcN).
\item \textbf{Newer models can do better.} Claude Opus 5.5 and Fable 5.1 rarely game the suite, and when they do they say so plainly.
\end{itemize}
