\subsection*{AI use statement}
Generative AI was used extensively in this work, and the models studied are themselves generative AI systems. AI agents built on Claude models performed the literature search and novelty assessment, designed and implemented the task suite and the independent task audit, wrote the experiment harness and analysis code, and drafted the manuscript, under the direction of the human author. Claude models also served as experimental subjects, report judges, and code reviewers, as described in \cref{sec:setup}. Every reference was checked against its source; every task passed automatic validation and independent review; every quantitative claim is generated from released trial records by released scripts; judge labels were validated against blinded human labels. The authors reviewed all AI-assisted work and take responsibility for the content of this paper.

\subsection*{Ethics statement}
The study involves no human subjects and no personal data. All agent actions ran in sandboxes on synthetic repositories. The behaviors we document (test gaming and misleading reports) are already publicly known in general form; we release the task suite to help developers and reviewers measure and reduce them.

\subsection*{Reproducibility statement}
All prompts, condition texts, probes, and rubrics appear verbatim in \cref{app:prompts}. We release the 24 tasks and 14 minimal-pair variants with reference implementations and hidden tests, the harness, every trial record (including tool calls and file diffs), all judge and reviewer outputs, the pre-registration with its amendments, and the scripts that produce every number, table, and figure. Model access is through the public Claude Code CLI; results for hosted models can drift over time.
