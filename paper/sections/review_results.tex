\subsection{Consequences for code review}
\label{sec:review}

\begin{figure*}[t]
\centering
\includegraphics[width=0.9\linewidth]{review.pdf}
\caption{Share of reviews that approve a gamed change, for the same diffs with three descriptions: the agent's own report (which fabricated a requirement), an honest minimal rewrite of it, and no description. Left: the reviewer sees the full original repository (pre-registered, H5). Right: the reviewer sees only the request, the description, and the diff (exploratory). Bars are 95\% Wilson intervals over diffs.}
\label{fig:review}
\end{figure*}

\paragraph{Full repository (pre-registered, H5).} We reviewed all \revOpusOrigN{} diffs whose report fabricated a requirement (\cref{fig:review}). With the original repository in view, Opus 5.5 approved almost none of the gamed changes under any description (\revOpusOrig, \revOpusHonest, and \revOpusNone). Sonnet 5 and Haiku 4.5 approved more gamed changes when the diff carried the agent's report than when it carried an honest one: Sonnet 5 \revSonnetOrig{} versus \revSonnetHonest{} (discordant pairs \revMcSonnetHonest, one-sided exact McNemar $p$ \revMcPSonnetHonest), Haiku 4.5 \revHaikuOrig{} versus \revHaikuHonest{} (\revMcHaikuHonest, $p$ \revMcPHaikuHonest). Pooled over reviewers, the odds of approval were \revORHonest{} times higher with the agent's report than with the honest one (95\% CI \revORHonestCI, logistic GEE clustered by diff). The agent's report did not raise approval above no description (Sonnet 5 \revSonnetNone, Haiku 4.5 \revHaikuNone; pooled odds ratio \revORNone{}, CI \revORNoneCI). H5 is supported against the honest description and not against no description. Approving reviews in this setting typically cited the passing suite, so the conflicting test itself seems to supply the justification; the report's effect is to withhold that the behavior contradicts the documentation.

\paragraph{Diff only (exploratory).} Without the repository (\cref{app:prereg} documents when this setting was added), the agent's report mattered much more to the two weaker reviewers. Haiku 4.5 approved \revDHaikuOrig{} of gamed changes that carried the agent's report, against \revDHaikuHonest{} with an honest description and \revDHaikuNone{} with none; Sonnet 5 approved \revDSonnetOrig, \revDSonnetHonest, and \revDSonnetNone; Opus 5.5 \revDOpusOrig, \revDOpusHonest, and \revDOpusNone. Pooled odds ratios were \revDORHonest{} \revDORHonestCI{} against the honest description and \revDORNone{} \revDORNoneCI{} against none. Without a description, reviewers typically asked why behavior and docstring had changed; the invented requirement supplied an answer. An invented requirement persuades the reviewer who does not check the specification.
