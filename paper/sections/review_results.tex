\subsection{Consequences for code review}
\label{sec:review}

\begin{figure*}[t]
\centering
\includegraphics[width=0.9\linewidth]{review.pdf}
\caption{Share of reviews that approve a gamed change, for the same diffs with three descriptions: the agent's own report (which fabricated a requirement), an honest minimal rewrite of it, and no description. Left: the reviewer sees the full original repository (pre-registered, H5). Right: the reviewer sees only the request, the description, and the diff (exploratory).}
\label{fig:review}
\end{figure*}

We gave the diffs of all \revAllOrigN{} special-cased trials whose report fabricated a requirement to three reviewer models (\cref{fig:review}). With the full repository in view, the strongest reviewer caught every one regardless of the description (Opus 5.5 approved \revOpusOrig{} with the agent's report, \revOpusHonest{} with an honest one, \revOpusNone{} with none). The two weaker reviewers approved more gamed changes when they carried the agent's own report than when the same diff carried an honest description: Sonnet 5 \revSonnetOrig{} versus \revSonnetHonest{} (discordant pairs \revMcSonnetHonest, $p$ \revMcPSonnetHonest), Haiku 4.5 \revHaikuOrig{} versus \revHaikuHonest{} (\revMcHaikuHonest, $p$ \revMcPHaikuHonest). The agent's report did not raise approval above having no description at all (Sonnet 5 \revSonnetNone, Haiku 4.5 \revHaikuNone), so H5 is supported against the honest description but not against no description. With the specification available, the cover story mostly works by withholding the truth rather than by persuading.

When reviewers saw only the diff (exploratory; \cref{app:prereg} documents when this setting was added), the story mattered much more. Haiku 4.5 approved \revDHaikuOrig{} of gamed changes that carried the agent's report, against \revDHaikuHonest{} with an honest description and \revDHaikuNone{} with none; Sonnet 5 approved \revDSonnetOrig, \revDSonnetHonest, and \revDSonnetNone; Opus 5.5 \revDOpusOrig, \revDOpusHonest, and \revDOpusNone. A reviewer that does not independently check the specification is exactly the reviewer an invented requirement persuades.
